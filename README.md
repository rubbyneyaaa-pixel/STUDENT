# Student Marks Calculator (SQLite, black and gold)

Files: index.html (Dashboard), calculator.html, students.html, reports.html, style.css (theme), app.js (all JavaScript).
Data is stored in a SQLite database (sql.js) inside the browser's IndexedDB.

## Run locally
Run `python -m http.server 8000` in this folder, then visit http://localhost:8000.
(An internet connection is needed for the sql.js library and Google Fonts.)

## Publish on GitHub Pages
Upload everything in this folder to your repository root and commit.
